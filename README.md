# Customer Churn Prediction

A Machine Learning web application that predicts whether a telecom customer is likely to leave a service.

## 🌐 Live Demo

[Open Customer Churn Prediction App](https://customer-churn-prediction-fgauf3lohgrgh2kvweef82.streamlit.app/)

## ✨ Features

- Predict customer churn using customer details
- Explore customer information and service usage
- Machine Learning model evaluation
- Interactive web interface built with Streamlit

## 🛠️ Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Machine Learning

## 📊 Model Performance

The Logistic Regression model achieved:

- Accuracy: 80.55%
- ROC-AUC: 0.8419

These results are from the model evaluation performed during development.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/pk0699629-hash/customer-churn-prediction.git
   ```

2. Open the project folder and install the dependencies listed in `requirements.txt`.

3. Start the application:

   ```bash
   streamlit run app.py
   ```
